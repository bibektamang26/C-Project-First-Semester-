# FinanceFlow - Bank Management System in C

A console-based Bank Management System developed in C as a first semester project.

This project demonstrates core programming concepts such as:
* Structures
* File Handling
* Functions
* Dynamic Memory Allocation
* Arrays
* Conditional Statements
* Loops
* Sorting
* Authentication System

## Features

### Admin Features
* Create new bank accounts
* View all accounts
* Update account information
* Delete accounts
* Sort accounts by balance

### Customer Features
* Login system
* Deposit money
* Withdraw money
* View mini statement
* Change password

## Files
* `main.c` → Main source code
* `users.txt` → Stores account data
* `transactions.txt` → Stores transaction history
